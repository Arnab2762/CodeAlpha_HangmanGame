# CodeAlpha Hangman Game

A simple text-based Hangman game developed using Python as part of my CodeAlpha Python Internship.

## 🎮 Features

- Randomly selects one word from 5 predefined words
- Player guesses one letter at a time
- Maximum 6 wrong guesses allowed
- Prevents duplicate guesses
- Validates user input
- Displays the current progress of the word
- Shows the correct word when the game ends

## 🛠️ Technologies Used

- Python
- random module
- Loops
- Conditional statements
- Strings
- Lists
- Functions/logic

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone this repository.
